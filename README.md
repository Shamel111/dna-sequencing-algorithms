# DNA Sequencing Algorithms

Hands-on practice in Bioinformatics using Python, as part of the *Algorithms for DNA Sequencing* course by Johns Hopkins University.

## Project Overview

This project explores fundamental concepts in DNA sequencing through practical implementations and data analysis.

## Topics Covered

* **Quality Control:** Exploring Phred quality scores in sequencing reads.
* **GC Content Analysis:** Analyzing GC content across read positions.
* **Naive Exact Matching:** Implementing a basic algorithm for matching sequencing reads against a reference genome.
* **Reverse Complement:** Extending the matching algorithm to account for reverse-complement sequences.

## Results

The read-matching implementation was extended to account for reverse-complement reads.

In the tested dataset, the number of matched reads increased from 459 to 932 out of 1,000 reads.
